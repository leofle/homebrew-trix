# homebrew-trix

The Homebrew tap for [trix](https://github.com/leofle/trix), a terminal workspace where coding agents live. Works on macOS and Linux, on Apple Silicon, Intel and ARM.

```sh
brew install leofle/trix/trix
```

`brew upgrade` picks up new releases. The formula installs the prebuilt binaries from trix's [releases](https://github.com/leofle/trix/releases).

Don't edit `Formula/trix.rb` here: trix's release workflow rewrites it for every release, from `packaging/homebrew-formula.sh` in the trix repo.
